## Cargo - Rust

### Initialization
Create a new directory:
```
cargo new project-name
```
Initialize in existing directory:
```
cargo init
```

### Layout

### Running
```
cargo run
```

### Dependencies
```
cargo add dependency-name
```

### Formatting
```
cargo fmt
```

### Checking
```
cargo check
```

### Linting
```
cargo clippy
```

### Testing
```
cargo test
```

### Building
Debug build:
```
cargo build
```
Release:
```
cargo build --release
```

### Documentation
```
cargo doc
```

### Maintenance
```
cargo update
```
